=== 머신러닝을 사용한 자동차 번호판 텍스트 인식 ===

-   목표 :
    자동차 이미지에서 번호판을 탐지하고 번호판의 텍스트를 문자열로 추출
    한개의 이미지에 포함된 다수개의 숫자/문자를 한꺼번에 인식할 수 있는 모델 개발
    YOLOv8-Seg : 자동차 이미지에서 번호판 탐지 및 추출
    CTC (Connectionist Temporal Classification) 모델 : 이미지가 텍스트를 포함할 때 문자열로 추출

-   연구과제

    1. YOLO를 사용하여 자동차 이미지로부터 번호판 탐지(YOLOv8-Seg 전이학습 요구됨)
    2. 탐지된 번호판만 오려내서 별도의 텍스트 이미지 파일로 저장
    3. 텍스트 이미지 파일에 대응하는 라벨 데이터 생성
    4. CTC 모델 학습 : 텍스트 이미지와 라벨 매핑 학습
    5. CTC 모델에 텍스트 이미지를 전달했을 때 그 안에 포함된 문자열을 추출할 수 있다
    6. Roboflow에서 프로젝트 생성시 타입을 Instance Segmentation으로 설정
