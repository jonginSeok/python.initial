모델의 측정 지표
 - Confusion matrix(혼동행렬):이진 분류의 경우

 실제값 | 예측값 | 예측: Positive | 예측: Nagative
===================================================
 실제 : Positive |       TP       |       FN
---------------------------------------------------
 실제 : Nagative |       FP       |       TN

  - TP, FP, TN, FN
  - TP: True Positive
  - FP: False Positive
  - TN: True Nagative
  - FN: False Nagative
  - 정확도(Accuracy): (TP + TN) / (TP + TN + FP + FN)   # 7/10 암환자 7명 10명을 진단
  - 정밀도(Precision): TP / {TP + FP}                   # 7/10 0으로 진단하지 않아 같다
  - 재현율(Recall, Sensitivity, 민감도): TP / (TP + FN) #
  - 조화평균(F1-Score)  2 - (Precision - Recall) / (Precision + Recall)
