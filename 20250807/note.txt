모델의 측정 지표
 - Confusion matrix(혼동행렬):이진 분류의 경우

 실제값 | 예측값 | 예측: Positive | 예측: Nagative
===================================================
 실제 : Positive |       TP       |       FN
---------------------------------------------------
 실제 : Nagative |       FP       |       TN

  - TP, FP, TN, FN
  - TP: True Positive
  - FP: False Positive
  - TN: True Nagative
  - FN: False Nagative
  - 정확도(Accuracy): (TP + TN) / (TP + TN + FP + FN)
  - 정밀도(Precision): TP / (TP + FP)
  - 재현율(Recall, Sensitivity, 민감도): TP / (TP + FN)
  - 조화평균(F1-Score)  2 * (Precision * Recall) / (Precision + Recall)

예제)
모델이 100명 중 20명을 Positive(질병 있음)이라고 예측함
 - 그 중 실제 질병 있는 사람(TP): 15명
 - 잘못 질병 있다고 한 사람(FP): 5명
 - 질병인데 놓친 사람(FN): 5명
 - 나머지 정상(TN): 75명

Accuracy  = (TP + TN) / 전체 = (15+75) / 100 = 0.90
Precision = TP / (TP + FP) = 15 / (15 + 5) = 0.75
Recall    = TP / (TP + FN) = 0.75
F1-Score  = 2 * (Precision * Recall) / (Precision + Recall)
          = 2 * (0.75 * 0.75) / (0.75 + 0.75) = 0.75
