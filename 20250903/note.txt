자동차 번호판 인식 포트폴리오

1. YOLOv8-Seg 모델 전이학습 / mAP 확인
2. 학습된 모델을 사용하여 번호판 안에 있는 텍스트만 인식하는지 바룬딩박스 그려서 확인
3. 1행인지 2행인지 확인하는 함수 작성
  - 텍스트라인이 1개이면 1행 번호판, 2행이면 2행 번호판

4. 바운딩 박스를 오려내서 이미지 파일에 저장 (plate, s1, d1, d2)
  - 번호판 : origin_name_plate.jpg                                      ex)서울32가1234_plate.jpg
  - 단행 텍스트 : origin_name_s1.jpg                                    ex)서울32가1234_s1.jpg
  - 2행 텍스트 : origin_name_d1.jpg(첫번째), origin_name_d2.jpg(두번째) ex)서울32가1234_d1.jpg(서울32) 서울32가1234_d2.jpg(가1234)

5. 이미지에 대한 라벨 생성 (image_path, label)
  - labels.cvs : c:/test/text_images/서울32가1234_d1.jpg                ex)서울32
    c:/test/text_images/서울32가1234_d2.jpg                             ex)가1234

6. 이미지와 라멜을 이용하여 CTC 모델 학습 / mAP 확인
7. 학습된 CTC 모델을 사용하여 자동차 번호판 텍스트 인식 실행
