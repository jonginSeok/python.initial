 ** 중간 점검 프로젝트 **

1. CNN 모델 학습시킴 -> 파일에 저장(cnn-model)
2. YOLO 모델 Pre-Trained 모델(80여가지 사물 탐지)
   - 전이학습(Transfer Learning) : 특정 사물의 이미지 탐지
   - 영상 안의 바운딩 박스를 알려주고 그것만이 특정 사물이라는 것을 인식시켜야 한다
   - 학습용 이미지 1000 개 -> 각각의 이미지에 바운딩박스 설정하고 텍스트파일에 저장
   - 전이학습 완성된 YOLO 모델 -> 파일에 저장(yolo-model)
3. yolo-model을 사용하여 이미지로부터 바운딩박스를 설정
   - 바운딩박스에 해당하는 영역의 픽셀을 crop한다
   - size_feats = img.size 
   - crop = transform(crop)
   - result = cnn-model(crop, size_feats)
