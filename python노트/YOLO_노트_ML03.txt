분류(Calssification)
 - Binary Calssification(이진분류)
   
   신경망 출력 노드 1개, 2개

   출력노드(tensorflow) 1개: Sigmoid(0~1사이의 값), BCELoss(Log함수) # BCELoss함수안에 Sigmoid 이 들어있음
   
   출력노드 2개: [1.2, 2.7], argmax(), Softmax(활성함수), CrossEntropyLoss # CrossEntropyLoss 함수안에 Softmax 이 들어있음
   # 예)위의 수치 이고 개와 고양이이면, 고양이일 것으로 출력:[1]

- Multi-classes Classification(다중분류)
  출력노드 2~n : Softmax, CrossEntropyLoss
  3개 노드 -> Softmax -> [0.2, 0.6, 0.2]  # 이 값을 argmax() 에 넣으면 [0, 1]로 출력(?)
  # 예) 5개의 노드이면 5개에 대한 확률(100%)값으로 출력

  argmax(logits, dim=1) # (200, 3) 200행 3열
