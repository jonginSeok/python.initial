한대의 하무수 안헤 다수개의 while 루프가 있다면

def test():
    while True:
        print('루프1') # pass

    while True:
        print('루프2') # pass

test()
print('프로그램 종료')

#################################

def test1():
    while True:
        print('루프1') # pass

def test2():
    while True:
        print('루프2') # pass

test1(); test2() # 동시에 돌아가지 않는다.
print('프로그램 종료')

#################################

t1 = threading.Thread(test1)
t2 = threading.Thread(test2)
t1.start(); t2.start()

io작업 ( 서버에 대한 요청 / 응답 )

요청 (게시판 1 페이지 요청) -> 응답(게시판 1페이지 수신) -> 화면에 출력
                        [기다림]

요청 (게시판 1 페이지 요청) -> 응답(게시판 1페이지 수신) -> 화면에 출력
                        [다른 로직 수행 가능]
                        [응답이 도착하면 콜백함수가 수신하여 사용]

비동기 : 요청/응답 때문에 다른 로직이 블로킹되지는 않는다.
쓰레드 : 로빅의 병행처리(수차적처리가 아님)
요청 -> 응답 ->  출력 : 5번 수행해야 하는 경우
